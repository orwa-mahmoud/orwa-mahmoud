## <img src="https://raw.githubusercontent.com/orwa-mahmoud/claude-nightshift/main/plugins/nightshift/assets/nightshift-logo.png" width="38" height="38" align="absmiddle" alt="Nightshift logo">&nbsp; Nightshift

### Accountable long-running coding shifts

[Nightshift](https://github.com/orwa-mahmoud/claude-nightshift) gives Codex and Claude Code an accountable engineering shift: persistent work, explicit completion, parked decisions, safety rules, and reviewable receipts.

<p align="center"><strong>Your punch list</strong> &nbsp;→&nbsp; <strong>Work that survives long sessions</strong> &nbsp;→&nbsp; <strong>A morning you can review</strong></p>

It can work your own plan or take a ready-made shift:

| 🔎 Product shift | 🧪 Quality shift | 🛡️ Maintenance shift |
|---|---|---|
| Research the product, competitors, weaknesses, and opportunities—then ship evidence-backed improvements | Increase meaningful coverage, clear lint and type debt, and hunt defects | Address security advisories, upgrade direct dependencies, and leave the repository healthier |

For Claude Code, hooks make the contract mechanical: no premature clock-out, no unattended 2 AM question blocking the run, owner-defined command and file safeguards, and recovery after an interrupted session.

## <img src="https://raw.githubusercontent.com/orwa-mahmoud/adapttable/main/apps/docs/public/favicon.svg" width="38" height="38" align="absmiddle" alt="AdaptTable logo">&nbsp; AdaptTable

### One data contract. Your choice of UI.

[AdaptTable](https://github.com/orwa-mahmoud/adapttable) removes the usual React-table compromise: choose a ready adapter for your UI kit or keep complete headless control, while the same core handles client and server data, mobile cards, URL state, filters, editing, and more.

<p align="center"><strong>One headless core</strong> &nbsp;→&nbsp; <strong>Seven UI ecosystems</strong> &nbsp;→&nbsp; <strong>The same product behavior everywhere</strong></p>

| Headless foundation | Product-grade behavior | UI freedom |
|---|---|---|
| One contract for client- and server-side data | URL state, reorder, pin, resize, virtualization, responsive mobile cards | Mantine, MUI, Chakra, Ant Design, Radix, Base UI, Tailwind/shadcn |
| Typed packages with independently published boundaries | First-class internationalization and RTL | Bring an adapter or build your own presentation |

It ships as a stable v2, **11-package npm monorepo** with documentation, starters, live examples, and an interactive demo.

## <img src="https://raw.githubusercontent.com/orwa-mahmoud/sight/main/docs/assets/three-eyed-raven.png" width="38" height="38" align="absmiddle" alt="Sight three-eyed raven logo">&nbsp; Sight

### An AI front desk that answers—and knows when not to.

[Sight](https://github.com/orwa-mahmoud/sight) is a multi-tenant AI front desk grounded in each business's own knowledge. It handles the conversation when it can and moves uncertainty to a human inbox when it cannot.

<p align="center"><strong>Customer message</strong> &nbsp;→&nbsp; <strong>Grounded answer</strong> &nbsp;→&nbsp; <strong>Human handoff when confidence ends</strong></p>

| Grounding | Conversations | Architecture |
|---|---|---|
| Hybrid retrieval with vector search, BM25, and reciprocal rank fusion | Per-contact memory, English and Arabic, WhatsApp and Telegram | Multi-tenant isolation, per-tenant model keys, DDD/CQRS backend |

LangGraph stays behind a clean orchestration boundary, keeping the rest of Sight ordinary, testable software.
